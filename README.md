# Modular Python Command-Line Calculator

A simple, reliable command-line calculator built in Python that performs basic arithmetic operations along with safe error handling.

## Features
- **Basic Operations:** Supports Addition, Subtraction, Multiplication, and Division.
- **Batch Mode:** Includes an 'All Operations' option to calculate all results at once.
- **Error Handling:** Uses `try-except` blocks to safely handle invalid inputs and division by zero without crashing.
- **Clean Structure:** Organized using modular, reusable Python functions.

## How to Run
1. Make sure Python is installed on your computer.
2. Download `calculator.py` from this repository.
3. Open your terminal or command prompt and run:
   python calculator.py
